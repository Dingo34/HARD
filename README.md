# HARD | HOUSTON — Roleplay Server

Официальный сайт RP-проекта **HARD | HOUSTON**.

## 🎮 О проекте

Город, для заранее написанного фильма. Здесь встречаются копы, банды, обычные люди и тысячи других историй.

## 🛠️ Стек

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP 8+, MySQL (PDO)
- **Хостинг:** Timeweb

## 📁 Структура

- `index.php` — главная страница
- `lore/`, `forum/`, `news/`, `fractions/`, `map/`, `professions/`, `changes/`, `community/` — внутренние страницы
- `auth.php` — регистрация и вход
- `apply.php` — подача заявки на персонажа
- `admin.php` — панель администратора
- `config.php` — подключение к БД (в `.gitignore`)
